# 設定と操作（Phase 16）

Phase 16までの機能を使って実戦データを収集できます。
Phase 17の配布EXEとPhase 18の最終テストは、実戦の設定調整・改善測定後に進めます。

## 起動から使用まで

1. 通常どおり起動し、Liveでゲーム音を取得するデバイスを選びます。
2. Liveの「Oracleサンプル 7/7種類」と入力のHz・chを確認します。未登録の種類はCalibrationで登録します。
3. Settingsで必要な項目を変更し、Stopした状態で「保存して適用」を押します。
4. LiveのRoundを選び、Startを押します。OverlayはLiveのボタンで表示できます。

設定を適用するには、音声取得とReplay・Calibration・評価の処理を止めます。
入力方式・デバイスの選択はLiveで行います。
未保存の変更は「変更を取り消す」で戻せます。「設定項目を初期値に戻す」も、保存して適用するまでは下書きです。
認識条件を適用すると、古い判定表示を消して再解析できる状態にします。
保存失敗時には元の設定を維持し、画面で案内します。

## Roundの操作

| 操作 | 動作 |
| --- | --- |
| Round選択 | 指定したRoundの提示を待ち直す |
| 前のRound / Next Round | 1〜5の範囲で移動する |
| このRoundをやり直す | 現在のRoundの両PASSと判定を消して待ち直す |
| Reset（Round 1） | Round 1からやり直す |
| 自動で次のRoundへ | 確定後の待機時間と連続した無音を確認して進む |

自動移行は初期ONです。LiveのチェックまたはSettingsで、Stop後に変更できます。
OFFの場合は確定順を保持し、Next RoundやResetを待ちます。
unknown・不一致だけで自動的に次へ進むことはありません。
音声の欠落、切断、設定変更、Stop、やり直し後は古い音を直近の確認候補として選べません。

## 音声の再接続

自動再接続は初期ON、間隔は2秒です。SettingsでON/OFFと0.25〜60秒の間隔を指定できます。
切断時は画面に状況が出て、「今すぐ再接続」で待機を短縮・再試行できます。
自動再接続がOFFでもこのボタンで再試行できます。Stopで再接続を中止します。
取得開始の処理中にStopを押した場合も、開始完了後に認識を再開しません。

再接続先は保存したAPI・デバイス名・Loopback区分で照合します。
番号やレートが変わった同じデバイスには接続し直し、別の既定デバイスへ勝手に切り替えません。
別の入力を使う場合はStop後に再検索・選択してください。

## Hotkey

**初期状態は無効です。** Settingsで割り当てと有効化を保存して適用します。

| 操作 | 初期の割り当て |
| --- | --- |
| Start / Stop | Ctrl + Alt + F7 |
| Reset（Round 1） | Ctrl + Alt + F8 |
| Next Round | Ctrl + Alt + F9 |
| Overlay表示の切替 | Ctrl + Alt + F10 |

Ctrl・Alt・Shiftのいずれかと、英字・数字・F1〜F24の組み合わせを指定します。
空欄にした操作は無効です。同じ組み合わせを複数の操作に割り当てることはできません。
F12はWindowsの予約キーのため使えません。[Windowsの仕様](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)

キーの長押しでは操作を繰り返しません。割り当て欄の編集中は登録を一時解除し、終了時にすべて解除します。
他のアプリと重複すると適用に失敗し、元の割り当てを復元します。別の組み合わせを指定してください。
編集中に別のアプリがキーを登録し、編集後の再登録に失敗した場合も画面に警告が出ます。
Hotkeyの操作でメイン画面を前面に呼び出すことはありません。
Startは入力の準備ができている場合に動作し、Next RoundはRound 5では動作しません。

## Overlayと認識条件

LiveのOverlay設定に「小・標準・大」のサイズ選択を追加しました。
基準サイズ・文字サイズ・倍率・表示方式・不透明度・クリック透過・位置調整も引き続き使えます。
配置を調整し終えたらドラッグ調整をOFFにします。

Settingsの「認識・提示間隔の調整を表示」で、検出・採用スコア、候補差、重み、
帯域、サンプル集約、内部レート、PASS間隔、タイムアウト、補正の上限などを変更できます。
波形とスペクトルの重みは合計1になるよう連動します。
しきい値の順序や帯域の組み合わせが不正なら、保存せずに案内します。
既存設定は新しい項目の初期値を補って読み込みます。

## 使用データを残す

測定用にはSettingsで「判定をログに保存」「unknown・不一致の音声を保存」をONにします。
成功例も比較する期間は「採用した音声も保存」をONにできます。初期OFFで、保存容量が増えます。
直近の長い区間が必要なら保存バッファを最大30秒まで増やし、Liveの保存操作でWAVを残せます。
自動収集は短いイベント音声です。実戦全体の通し録音は自動収集しません。

通常の保存先は以下です。

```text
%LOCALAPPDATA%\OracleAssistant\
  config.json          使用設定
  logs\                判定JSONL・イベント音声・application.log
  review\cases\        手動で正解・分類を付けた音声
  templates\           登録音声
```

使用データの確認には、判定ログと対応音声、使用設定、分かる範囲の正解順・Round・困った場面のメモを使います。
正解を付けたケースや通しWAVがあれば、同じ音声で改善前後を比較できます。
詳細は[実戦記録](gameplay-review.md)と[Dataset評価](dataset-evaluation.md)を参照してください。

ユーザー向けの案内は画面に表示します。
音声ドライバー・ファイル操作・Hotkey登録の例外と詳細はlogsのapplication.logに記録します。
