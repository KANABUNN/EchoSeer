# Phase 3 — Oracle サンプルの登録

## WAV を登録する

1. アプリを起動し、Calibration タブを開きます。
2. 上部で L1 / L2 / L3 / MID / R1 / R2 / R3 を選びます。
3. Import WAV で、その Oracle の音声ファイルを選びます。複数選択できます。
4. 一覧からサンプルを選び、入力の Peak / RMS / 長さ / レート / チャンネル数と品質警告を確認します。
5. Listen で確認します。Windows の現在の既定出力を使い、再生音量の初期値は 20% です。再生を停止できます。

登録は Oracle ごとに何度でも追加できます。既存サンプルを上書きしません。
選択欄の括弧内は、各 Oracle の有効なサンプル数です。
表示名は config.json の oracle_labels、保存先の識別には固定の Oracle ID を使います。
小さいウィンドウでは画面をスクロールしてください。

## Live の音声を録音する

1. Live でゲーム音を取り込むデバイスを選び、Start で LIVE にします。
2. Calibration で Oracle と録音時間を選びます。初期 2 秒、0.1〜10 秒です。
3. Record Sample を押して、その Oracle の音を収録します。
4. 進捗が 100% になると自動登録されます。登録後は品質表示と Listen で確認します。

開始前のリングバッファは録音対象に含めません。
指定時間に相当する native 音声フレームを取得してから、登録用の前処理を行います。
録音を中止・Live の Stop・入力切断・音声欠落・取得タイムアウトでは、途中の音声を登録しません。
録音後も Live の取得は続きます。終了操作で取得と録音・保存・再生を終了します。

Listen の出力を取り込む loopback を選ぶと、再生したサンプルも Live に入ります。
実 Oracle サンプルを録音するときは、目的のゲーム音だけを取り込んでください。

## 品質と対応形式

登録音声はチャンネル平均 → DC 除去 → 内部レート変換 → peak 0.95 正規化です。
内部レートの初期値は 48000 Hz、保存は mono / float32 WAV です。
元の native レート・チャンネル数・サンプル値を別の float32 WAV に保存します。
Import 元ファイルを変更しません。元 WAV の PCM エンコードや付加情報の保持とは異なります。

- 入力は 0 秒より長く 10 秒以内。WAV の対応形式・ファイルサイズ制限は Replay と共通です。
- 前処理後の無音、DC だけの音声、逆位相で打ち消される音声は登録を拒否します。
- 短い音声（0.1 秒未満）、長めの音声（5 秒超）、小さな RMS、最大振幅付近は警告を保存します。
- 微小音声は共通前処理の peak 1e-6 以下で無音として扱います。
- 録音の native 配列は 64 MiB 以下。高レート・多チャンネルで超える場合は録音時間を短くしてください。

警告は機械的な目安です。Oracle の音全体を含み、周囲の効果音・会話を減らしたサンプルを登録してください。
この Phase はサンプル管理までです。Oracle の分類・スコア・認識率の評価は後続 Phase です。

## 保存と削除

通常の保存先は %LOCALAPPDATA%/OracleAssistant/templates/ です。
--data-dir を指定した場合は、そのフォルダー内の templates/ を使います。

```text
templates/
  samples/
    L1/
      <sample_id>/
        sample.wav       前処理済み mono 音声
        original.wav     native 音声
        metadata.json    Oracle、日時、形式、品質、SHA-256 など
    L2/ … R3/
  .trash/                削除したサンプル
```

保存途中のフォルダーから、3 ファイルが揃ったサンプルをまとめて登録します。
書込み・キャンセル・公開失敗では新しい未完成サンプルを一覧へ出さず、既存サンプルを保護します。
アプリの再起動後も登録内容を読み込みます。「再読込」でも一覧を更新できます。
破損した情報や音声は警告し、正常なサンプルを引き続き表示します。破損データを自動削除しません。
内部レート設定と異なる保存サンプルは警告し、元の保存形式を維持します。

Delete は選択したサンプルを .trash/ へ移します。
「削除を戻す」はこの起動中に最後に削除した 1 件を復元します。
アプリ終了でボタンの履歴は失われますが、退避したファイルは残ります。
保存データを保管する場合は templates/ 全体をコピーしてください。
