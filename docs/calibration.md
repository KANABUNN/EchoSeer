# Phase 3・12 — Oracleサンプルの登録と品質確認

Calibrationで7種類のサンプルを作成できます。コードや保存フォルダーの直接操作は不要です。
上部のボタンにOracleごとのサンプル数、登録済み種類数、未登録位置を表示します。
7種類が揃うと「7種類を比較できます」と表示します。

## WAVを登録する

1. CalibrationのOracleボタンまたは選択欄で固定IDを選びます。
2. Import WAVで、そのOracleの音声を選びます。複数選択できます。
3. 一覧でサンプルを選び、Quality Checkを押します。
4. 入力のPeak / RMS / 長さ / レート / チャンネル数、クリッピングと警告を確認します。
5. Listenで確認します。Windowsの既定出力を使い、再生音量の初期値は20%です。再生を停止できます。

固定IDはL1 / L2 / L3 / MID / R1 / R2 / R3です。
表示名は「表示名を保存」で変更できます。空の名前は保存できず、40文字までです。
Live、Oracle Map、Overlay、Replayへ反映し、サンプルの固定IDや元の認識を変えません。

提供A〜Gの対応は[認識の説明と対応表](recognition.md)に記載しています。
新しい環境の音声を登録するときも、選択した位置の音と固定IDが対応していることを確認してください。

## 録音する

1. Liveの入力方式と音声デバイスを選び、Startを押します。
2. CalibrationでOracleと録音時間を選びます。初期2秒、0.1〜10秒です。
3. Record Sampleを押して、そのOracleの音を収録します。
4. 進捗100%で自動登録されます。Quality CheckとListenで確認します。

開始前のバッファは録音対象にしません。
録音を中止した場合、入力停止・欠落・overflow・時間超過の場合、未完成サンプルを登録しません。
録音中・保存中はOracleの選択を固定して、途中の選択変更で別IDへ保存しません。

Live認識はCalibrationの録音・保存・再生・削除・品質確認中に一時停止します。
音声取得は継続し、完了後は現在のRoundを空の列で再開します。
Oracleの提示前にCalibrationを終えてください。

## Quality Check

選択した保存音声を再読込し、音声とchecksumの整合を確認してから品質を測定します。
元のnative音声を使うので、正規化後の見かけの音量を録音音量として表示しません。
保存したWAV・metadataを書き換えません。元音声が破損・変更・欠落していれば失敗として表示します。

| 表示 | 意味 |
|---|---|
| 警告なし | 現在の保存音声で品質警告なし。Oracleの正誤は未判定 |
| 要確認 | 短い／長い／小音量／クリッピングなどの警告あり |
| 失敗 | 保存音声を検証・読込できない |

サンプルを選び直すと前の品質確認結果を消し、別のサンプルの結果を表示しません。
「登録情報を表示」で登録時の形式・日時・品質・IDなどを開けます。
再読込は現在のサンプル数と破損情報も更新します。

登録音声はチャンネル平均 → DC除去 → 内部レート変換 → peak 0.95正規化です。
元のnative音声もfloat32 WAVとして保持します。サンプルは10秒以内です。
無音・DCのみ・左右の逆位相による消失は拒否し、短さ・長さ・微小音量・最大振幅付近を警告します。
PCM 8 / 16 / 24 / 32 bit、float 32 / 64 bit、対応WAVE_FORMAT_EXTENSIBLEを読めます。

## 削除と保存

Deleteは選択したサンプルを削除済み領域へ移し、「削除を戻す」で最後の削除を復元できます。
既存サンプルを保護し、一時保存を完了したものだけ一覧へ公開します。

保存先の初期値は%LOCALAPPDATA%/OracleAssistantです。
templates/samples/<固定ID>/<sample ID>/に前処理済みsample.wav、
native original.wav、metadata.jsonを保存します。
表示名・Map配置・Overlay設定はconfig.jsonへ保存します。

## 確認範囲

GUIから各Oracleを登録・品質確認し、件数の更新、削除・復元、表示名の保存・再起動を検証しました。
録音・品質確認中の終了、保存音声の破損、品質警告、元ファイルを変更しないことも検証しています。
Windows画面で提供7音声を登録・品質確認し、登録後の連続Live認識へつなぎました。
録音操作はデバイス代替の音声で確認しています。
実ゲーム中の手動録音、独立した録音・実戦の認識率と誤検出率は未確認です。
